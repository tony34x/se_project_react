### 🌦️ What to Wear? (WTWR)

A responsive, dynamic React web application designed to help users select appropriate clothing outfits based on real-time local weather conditions. The application interfaces with an external weather API to determine temperature and environmental conditions, automatically filtering and suggesting configured wardrobe items.

### 🛠️ Tech Stack & Architecture

* **Frontend Library:** React.js (Functional components, hooks)
* **Build Tool:** Vite (Optimized production asset bundling)
* **API Integration:** Native Fetch API / Axios for asynchronous weather data fetching
* **Styling:** Modular CSS / BEM methodology for responsive layout structures
* **State Management:** React Context API / useState hooks for managing wardrobe inventory and user preferences

### ✨ Key Features

* **Real-Time Data Parsing:** Fetches live weather updates based on the user's location coordinates.
* **Intelligent Wardrobe Filtering:** Dynamically renders clothing cards categorized by temperature thresholds (Hot, Warm, Cold).
* **Interactive UI:** Smooth transitions, responsive design for mobile and desktop screens, and custom modal handling for adding new clothing assets.
* **Secure Environments:** Production-safe API key handling utilizing environment variables.
