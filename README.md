# WTWR

WTWR, short for "What to Wear?", is a React app that helps users choose clothing based on the current weather. The app fetches live weather data, displays the current temperature and location, and filters clothing cards by weather type so users see items that match the conditions.

## Functionality

- Fetches current weather data from the OpenWeather API
- Displays the current temperature in Fahrenheit
- Displays the current location in the header
- Shows a weather card with condition-specific imagery
- Filters clothing items by hot, warm, or cold weather
- Lets users add new clothing items through a reusable modal form
- Opens clothing cards in a preview modal

## Technologies

- React
- Vite
- JavaScript
- CSS
- OpenWeather API
- ESLint
- Prettier
